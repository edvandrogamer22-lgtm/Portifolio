# History of Legends

Projeto web estático em HTML, CSS e JavaScript.

## Como executar
1. Baixe ou clone este repositório.
2. Abra `index.html` no navegador. Para uma experiência mais fiel, use a extensão **Live Server** no VS Code.

## Publicar no GitHub Pages
1. Envie todos os ficheiros deste projeto para um repositório GitHub.
2. Abra **Settings → Pages**.
3. Em **Build and deployment**, selecione **Deploy from a branch**.
4. Escolha a branch `main` e a pasta `/ (root)`, depois clique em **Save**.

Os vídeos foram comprimidos para reduzir o tamanho do projeto. Mantêm os mesmos caminhos usados pelo site.
